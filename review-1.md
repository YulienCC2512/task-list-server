# ¿Qué es mi producto y para qué sirve?

Task List Server es una aplicación que permite organizar tareas de manera simple, rápida y eficiente.

Su propósito es ayudar a personas y equipos a gestionar sus actividades diarias, organizar pendientes y hacer seguimiento del progreso de cada tarea.


# ¿Cuáles son las funcionalidades más importantes y por qué los usuarios las usarían?

## Crear tareas
Permite registrar nuevas actividades fácilmente. Los usuarios pueden agregar tareas en segundos para no olvidar pendientes importantes.

## Listar tareas
Muestra todas las tareas registradas en el sistema. Esto permite tener una visión clara y organizada de lo que se debe hacer.

## Actualizar tareas
Permite modificar información de una tarea, como marcarla como completada. Esto facilita el seguimiento del progreso y el control del trabajo realizado.

## Eliminar tareas
Da la opción de borrar tareas que ya no son necesarias. Esto ayuda a mantener la lista organizada y actualizada.

# ¿Qué tecnologías usaste y por qué?

## Node.js
Se utilizó para construir el servidor de la aplicación, ya que permite crear sistemas rápidos, eficientes y escalables.

## Express.js
Facilita la creación de rutas y el manejo de solicitudes de manera sencilla y organizada.

## GitHub
Se utilizó para el control de versiones del proyecto, permitiendo trabajar con ramas, mantener el orden del desarrollo y asegurar una mejor gestión del código.
